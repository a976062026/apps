网盘源管理（一键添加 Alist 网盘）

  
这里维护的网盘会写入 apps.json 的 alist_sources 字段，App 启动后自动拉取，首页搜索框下方可一键切换。字段：名称 + Alist 地址（如 https://pan.iosxn.cn）。

  

  

  

    
  

  






  
停用路径 / 屏蔽词 / 公告（写入 apps.json）

  
停用路径：隐藏历史版本等，每行一个，可填完整路径或文件名。屏蔽词：命中关键词的资源与文件夹全部隐藏，用户搜该关键词按无结果处理，每行一个。公告：打开 App 时展示一次（可关闭），留空则不展示。

  

  

  

    
    
  

  
  

  

  

  

    
  






  
一键发布（保存并提交到 GitHub）

  
点「保存并发布」= 把当前内容（软件/网盘源/停用/公告/白名单等）直接提交到你的仓库，免去导出上传。Token 只存本浏览器（localStorage），可在 GitHub 随时撤销。
